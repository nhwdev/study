## 저장소 구성

각 폴더는 기존 프로젝트의 파일 구조를 그대로 유지합니다. 실행 방법과 개발 환경은 각 프로젝트의 문서와 설정을 참고하세요. 전체 프로젝트를 하나의 애플리케이션으로 빌드하거나 실행하도록 구성한 저장소는 아닙니다.

기존 공개 저장소 7개의 기본 브랜치와 해당 브랜치의 전체 커밋 기록을 통합했습니다. 기존 커밋 ID는 유지되며, 통합 이전 커밋에서는 파일이 당시의 원래 경로에 있습니다. 원본 저장소는 별도로 보관됩니다.

비공개 저장소 `shop`은 포함하지 않았습니다.
